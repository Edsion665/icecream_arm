## 串口1 角度控制协议说明

### 1. 总体约定

- 物理接口：`USART1`，引脚 `PA9` (TX)、`PA10` (RX)
- 串口参数：`9600 8N1`（9600 波特率，8 数据位，无校验，1 停止位）
- 传输格式：**一条命令 = 一行 ASCII 文本**，以 `\r\n`（推荐）或至少 `\n` 结束

在普通角度控制指令之前，**增加一次握手流程**（可由上位机配置开启/关闭）：

1. 树莓派上电、串口打开后，先发送：

   `start\r\n`

2. STM32 收到 `start` 后，立即回：

   `ok\r\n`

3. 树莓派在配置的超时时间内收到包含 `ok` 的一行，即认为握手成功，开始后续 `DATA:...` 控制指令发送；
4. 若在超时时间内未收到 `ok`，则认为连接异常，关闭串口并按原有重连策略重试。

### 2. 帧格式

一行命令的格式为（注意为一行文本，并以 `\r\n` 或至少 `\n` 结束）：

`DATA:a0,a1,a2,a3,a4,a5*XX\r\n`

含义：

- **`DATA:`**：帧头（固定）
- **`a0..a5`**：6 个整数，单位是 **度×100**
  - 例如：
    - 90.00° → `9000`
    - -30.50° → `-3050`
    - 0° → `0`
  - 分隔符可以是逗号或空格，混用也可以，下面几种写法都合法：
    - `100,200,300,400,0,0`
    - `100 200 300 400 0 0`
    - `100, 200, 300, 400, 0, 0`
- **`*XX`**：2 位十六进制校验和（不区分大小写，如 `3F` 或 `3f`）
- **`\r\n`**：行结束符，推荐使用

### 3. 校验和 XX 的计算方法

1. 取 **从 `DATA:` 后面开始，到 `*` 前一个字符结束** 这一段字符串的所有字节（即 `DATA:...` 的全部内容，*不包含* `*` 和校验码本身）。  
   对于帧：

`DATA:100,200,300,400,0,0*XX\r\n`

   参与校验的内容是：

`DATA:100,200,300,400,0,0`

2. 对上述内容的每一个字节做 8 位异或（XOR）：

   - 初值：`cs = 0`
   - 对每个字节：`cs ^= byte`
   - 结果 `cs` 范围为 0–255

3. 将 `cs` 转换为 **两位十六进制字符串**（高位在前，不足两位时补零），即为 `XX` 字段。

#### 3.1 伪代码示例（Python）

```python
payload = b"DATA:100,200,300,400,0,0"  # 注意：不含 '*' 和校验码本身
cs = 0
for b in payload:
    cs ^= b
print(f"{cs:02X}")  # 输出两位十六进制，如 '3F'
```

### 4. 示例

#### 4.1 示例 1：简单 6 角指令

目标角度（单位：度×100）：

- a0..a5 = `100, 200, 300, 400, 0, 0`

参与校验的字符串为：

`DATA:100,200,300,400,0,0`

假设按第 3 节的算法计算得到校验和为 `0xXX`，则完整一帧为：

`DATA:100,200,300,400,0,0*XX\r\n`

上位机/树莓派端只需按此格式构造字符串并发送即可。

#### 4.2 示例 2：带负数的指令

目标角度（单位：度）：

- 轴0：  90.00° → `9000`
- 轴1： -45.50° → `-4550`
- 轴2：   0.00° → `0`
- 轴3：  30.00° → `3000`
- 轴4：   0.00° → `0`
- 轴5：   0.00° → `0`

载荷部分为：

`DATA:9000,-4550,0,3000,0,0`

按 XOR 规则计算出校验和为 `0xXX`（示例），则完整一帧为：

`DATA:9000,-4550,0,3000,0,0*XX\r\n`

### 5. STM32 端行为简述（供参考）

1. 串口1（USART1）按行接收数据，中断中组装到 `g_rpi_line`，检测到行结束符（`\r` 或 `\n`）后置位 `g_rpi_line_ready`。
2. 主循环中发现 `g_rpi_line_ready == 1` 时：
   - 复制一份到本地缓冲 `line[]`；
   - 检查是否以 `DATA:` 开头、是否包含 `*`；
   - 按第 3 节规则计算 XOR 校验并比对 `XX`；
   - 若校验通过，则从 `DATA:` 后面的载荷中解析出 6 个整数 `a0..a5`；
   - 将 `a0..a5` 依次写入 `int16_t raw6[6]`，调用 `Process_Rpi_Raw6(raw6)` 进行后续角度规划和电机控制；
   - 若校验或格式错误，会通过串口2输出调试信息（如 `[RX1] checksum fail or format err`）。

3. 在角度指令 `DATA:...` 之前增加握手逻辑：

   - 上电后 STM32 开始监听串口1；
   - 当收到一行文本等于 `start`（忽略行尾 `\r\n`，可适当忽略大小写）时，通过串口1 回复一行：

     `ok\r\n`

   - 树莓派端收到 `ok` 后开始发送 `DATA:...` 控制指令；
   - 如有需要，STM32 也可以在握手后额外发送一行版本信息（例如 `[INFO] stm32 ready`），上位机按普通调试串口文本处理即可。

4. 角度的内部处理方式（`raw6[]` → 世界坐标 → 四电机同步运动）保持不变，仅在协议层增加了头帧和校验机制以及可选握手过程，以增强鲁棒性并防止吞帧/误帧。
